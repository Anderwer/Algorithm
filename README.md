# Algorithm

个人算法竞赛仓库，主要用于整理：

- `Codeforces` 比赛代码
- 常用算法模板
- 专题学习笔记
- 赛后知识点总结

这个仓库的目标不是做成“大而全”的资料堆，而是尽量保持成一套：

- 能直接复用
- 方便复习
- 结构清晰
- 适合长期维护

的个人算法仓库。

---

## 目录结构

### 1. `algorithm/`
用于存放 **可以直接复制使用的代码模板**。

这里的内容更偏“比赛实战模板”，例如：

- 树状数组
- 线段树
- 并查集
- LCA
- 最短路
- 拓扑排序
- Trie
- 字符串哈希
- 组合数
- 欧拉路
- FFT / NTT
- 数位 DP 骨架
- 莫队
- Functional Graph

特点：

- 接口尽量统一
- 尽量不依赖题目特定全局变量
- 更适合比赛时直接复制修改

如果你想看每个模板的说明，可以继续看：

- `algorithm/README.md`

---

### 2. `notes/`
用于存放 **专题讲义、知识点笔记、学习总结**。

这里的内容更偏“学习材料”，例如：

- 图论
- 数论专题
- DP 专题
- 树的相关知识
- SG 定理
- 线性 DP（最长子序列）

特点：

- 更适合阅读和复习
- 更偏解释和总结
- 不一定适合直接复制进比赛代码

---

### 3. `Codeforces/`
用于存放 Codeforces 比赛代码与比赛总结。

目前已经按比赛类型做了物理分类，例如：

- `Div. 2`
- `Div. 3`
- `Div. 4`
- `Div. 1&2`
- `Educational`
- `Global`
- `Special`

此外，部分比赛目录下还会保留：

- 场次知识点总结
- 更适合导出 PDF 的讲义型总结

如果你想快速按比赛类型查找，可以看：

- `Codeforces/Codeforces分类索引.md`

---

## 仓库使用原则

### 1. 模板和笔记分开
- `algorithm/` 放模板
- `notes/` 放讲义和笔记

这样可以避免“代码模板”和“学习材料”混在一起。

### 2. 比赛代码按场次保存
比赛目录尽量保留原始场次信息，方便以后：

- 回看某一场比赛
- 复盘某一类题目
- 按比赛节奏复习

### 3. 知识点总结尽量沉淀
做完一场比赛后，尽量把其中值得反复吸收的内容总结下来，而不是只留下 AC 代码。

## 当前仓库适合用来做什么

### 1. 比赛时查模板
如果你已经知道自己要用什么算法，可以直接去：

- `algorithm/`

找对应模板。

### 2. 赛后复习
如果你想系统复习某类知识点，可以去：

- `notes/`

看专题笔记。

### 3. 按比赛类型刷题
如果你想按 `Div.2 / Div.3 / Edu / Global` 这种维度做训练，可以去：

- `Codeforces/`

按分类目录找对应比赛。

## 推荐使用方式

### 如果你是自己复习
建议顺序：

1. 先看 `Codeforces/` 中做过的比赛
2. 再把总结过的知识点对应到 `notes/`
3. 最后把高频算法沉淀到 `algorithm/`

这样能形成：

- 比赛代码
- 知识点总结
- 通用模板

三层闭环。

### 如果你是直接拿模板
建议优先使用：

- `algorithm/README.md`

先看模板索引，再决定复制哪个文件。
