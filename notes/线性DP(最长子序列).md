# 线性DP（最长子序列）笔记

## 一、这一类问题在研究什么

“最长子序列”问题的核心，不是连续的一段，而是：

- 可以从原序列中删掉一些元素
- 保留相对顺序不变
- 问满足某种性质的最长长度是多少

这里最常见的四类是：

1. 最长上升子序列 `LIS`
2. 最长不下降子序列 `LNDS`
3. 最长下降子序列 `LDS`
4. 最长不上升子序列 `LNIS`

这类问题非常重要，因为它既是经典线性 DP，又常常和：

- 二分优化
- 偏序
- 贪心
- Dilworth 定理

联系在一起。

---

## 二、什么叫“子序列”

给定序列：

`1 5 2 4 3`

你可以选出：

- `1 2 4`
- `1 2 3`
- `1 5`

这些都叫子序列。

但你不能选：

- `5 1`
- `4 2`

因为子序列要求 **相对顺序不变**。

很多初学者会把“子序列”和“子串 / 子数组”混掉，这是第一个要避免的错误。

---

## 三、最长上升子序列（LIS）

## 1. 问题定义

给定序列 `a[1..n]`，求一个最长的严格上升子序列长度。

也就是要求：

$$
a_{i_1} < a_{i_2} < \cdots < a_{i_k}
$$

其中：

$$
1 \le i_1 < i_2 < \cdots < i_k \le n
$$

让这个 `k` 尽量大。

---

## 2. 最朴素的线性 DP 做法：`O(n^2)`

这是最应该先理解的版本。

### 状态定义

设：

- `dp[i]` 表示 **以 `a[i]` 结尾** 的最长上升子序列长度

为什么这样定义？

因为“以 `a[i]` 结尾”之后，转移就很自然：

- 如果前面某个 `a[j] < a[i]`
- 那么 `a[i]` 就可以接在以 `a[j]` 结尾的上升子序列后面

于是有转移：

$$
dp[i] = \max(dp[i], dp[j] + 1), \quad j < i,\ a[j] < a[i]
$$

### 初始化

每个元素自己都可以单独构成长度为 `1` 的上升子序列，所以：

$$
dp[i] = 1
$$

### 答案

最终答案是：

$$
\max(dp[i])
$$

因为最长上升子序列可能以任意位置结尾。

---

## 3. 为什么这个状态定义很经典

很多同学刚学 DP 时容易这样想：

- `dp[i]` 表示前 `i` 个数中的 LIS 长度

这种定义不是不能做，但转移通常不如“以 `i` 结尾”自然。

“以某个位置结尾”的定义有两个优点：

1. 状态含义清晰
2. 转移条件直接来自“能不能接在前面”

所以以后做子序列类 DP，优先考虑：

- 以 `i` 结尾
- 以 `i` 开头
- 以 `i,j` 为边界

这种“带约束的状态”往往更好转移。

---

## 4. `O(n^2)` 模板

```cpp
#include <bits/stdc++.h>
using i64 = long long;
using namespace std;

// 最长上升子序列 O(n^2)
// a 使用 1 下标
int LIS_n2(const vector<int>& a)
{
    int n = (int)a.size() - 1;
    vector<int> dp(n + 1, 1);
    int ans = 0;

    for(int i = 1; i <= n; i++)
    {
        for(int j = 1; j < i; j++)
        {
            if(a[j] < a[i])
            {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        ans = max(ans, dp[i]);
    }

    return ans;
}
```

## 四、最长上升子序列的二分优化：`O(n log n)`

这是竞赛中最常用的版本。

很多同学会背这个做法，但不真正理解。  
这里重点讲它为什么成立。

---

## 1. 核心维护的量是什么

我们维护一个数组 `f`，含义是：

- `f[len]` 表示长度为 `len` 的上升子序列中，**结尾最小** 的那个结尾值

这个定义很关键。

注意，不是说 `f` 真的是某条 LIS。  
而是说：

- 对每个长度 `len`
- 我们只关心“能做到这个长度时，最小的结尾是多少”

为什么只关心最小结尾？

因为结尾越小，后面越容易接新数。

这就是这套做法的本质贪心思想。

---

## 2. 为什么 `f` 一定是单调的

如果：

- `f[1]` 是长度为 `1` 的最小结尾
- `f[2]` 是长度为 `2` 的最小结尾
- ...

那么显然有：

$$
f[1] < f[2] < f[3] < \cdots
$$

因为一个更长的严格上升子序列，它的结尾一定要比前一层更大。

既然 `f` 单调，就可以二分。

---

## 3. 每读到一个数 `a[i]` 时该怎么办

分两种情况：

### 情况 1：`a[i] > f[len]`

说明它可以直接接在当前最长上升子序列后面：

- 长度增加 `1`
- 更新 `f[++len] = a[i]`

### 情况 2：`a[i] <= f[len]`

说明它不能让最长长度增加。  
但它可能可以去更新某个位置，让某个长度的结尾变得更小。

具体做法：

- 找到最小的 `pos`，使得 `f[pos] >= a[i]`
- 然后令 `f[pos] = a[i]`

为什么这样做对？

因为：

- 长度为 `pos` 的某个上升子序列，本来结尾是 `f[pos]`
- 现在换成更小或相等的 `a[i]`
- 不会让这个长度失效
- 反而会让后续更容易接新数

这就是“贪心替换”的本质。

---

## 4. `O(n log n)` 模板

```cpp
#include <bits/stdc++.h>
using i64 = long long;
using namespace std;

// 最长上升子序列 O(n log n)
// a 使用 1 下标
int LIS(const vector<int>& a)
{
    int n = (int)a.size() - 1;
    vector<int> f(n + 1, 0);
    int len = 0;

    for(int i = 1; i <= n; i++)
    {
        if(len == 0 || a[i] > f[len])
        {
            f[++len] = a[i];
        }
        else
        {
            int pos = lower_bound(f.begin() + 1, f.begin() + len + 1, a[i]) - f.begin();
            f[pos] = a[i];
        }
    }

    return len;
}
```

---

## 5. 为什么这里用 `lower_bound`

因为是 **严格上升**。

我们要找到第一个：

$$
f[pos] \ge a[i]
$$

的位置替换掉它。

这样可以保证：

- 相同元素不会让长度错误增长
- 严格上升的条件被正确维护

---

## 五、最长不下降子序列（LNDS）

## 1. 问题定义

不下降就是允许相等，也就是：

$$
a_{i_1} \le a_{i_2} \le \cdots \le a_{i_k}
$$

---

## 2. 和 LIS 的区别

只有两个改动：

1. 判断能否接到最后时，把 `>` 改成 `>=`
2. 二分替换时，把 `lower_bound` 改成 `upper_bound`

为什么？

因为允许相等，所以相等的数也可以接上去。  
因此在替换时，要找第一个：

$$
f[pos] > a[i]
$$

的位置，也就是 `upper_bound`。

---

## 3. 模板

```cpp
#include <bits/stdc++.h>
using i64 = long long;
using namespace std;

// 最长不下降子序列 O(n log n)
// a 使用 1 下标
int LNDS(const vector<int>& a)
{
    int n = (int)a.size() - 1;
    vector<int> f(n + 1, 0);
    int len = 0;

    for(int i = 1; i <= n; i++)
    {
        if(len == 0 || a[i] >= f[len])
        {
            f[++len] = a[i];
        }
        else
        {
            int pos = upper_bound(f.begin() + 1, f.begin() + len + 1, a[i]) - f.begin();
            f[pos] = a[i];
        }
    }

    return len;
}
```

---

## 六、最长下降子序列（LDS）

严格下降：

$$
a_{i_1} > a_{i_2} > \cdots > a_{i_k}
$$

有两种常见做法：

### 做法 1：直接把比较符号反过来

### 做法 2：把所有数取负，再求 LIS

第二种做法也很常见，因为：

- 严格下降 `a[i] > a[j]`
- 等价于 `-a[i] < -a[j]`

---

## 1. 直接写法模板

```cpp
#include <bits/stdc++.h>
using i64 = long long;
using namespace std;

// 最长下降子序列 O(n log n)
// a 使用 1 下标
int LDS(const vector<int>& a)
{
    int n = (int)a.size() - 1;
    vector<int> f(n + 1, 0);
    int len = 0;

    for(int i = 1; i <= n; i++)
    {
        if(len == 0 || a[i] < f[len])
        {
            f[++len] = a[i];
        }
        else
        {
            int l = 1, r = len, pos = len;
            while(l <= r)
            {
                int mid = (l + r) >> 1;
                if(f[mid] <= a[i])
                {
                    pos = mid;
                    r = mid - 1;
                }
                else l = mid + 1;
            }
            f[pos] = a[i];
        }
    }

    return len;
}
```

---

## 七、最长不上升子序列（LNIS）

允许相等的下降：

$$
a_{i_1} \ge a_{i_2} \ge \cdots \ge a_{i_k}
$$

同理，也可以：

- 直接修改比较符号
- 或者把所有数取负后做 LNDS

---

## 八、这四类题的统一记忆方法

建议你不要分别死记四个模板，而是记住下面这个表：

| 类型 | 尾部扩展条件 | 二分函数 |
|---|---|---|
| LIS（严格上升） | `a[i] > f[len]` | `lower_bound` |
| LNDS（不下降） | `a[i] >= f[len]` | `upper_bound` |
| LDS（严格下降） | `a[i] < f[len]` | 自定义二分 / 取负转 LIS |
| LNIS（不上升） | `a[i] <= f[len]` | 自定义二分 / 取负转 LNDS |

真正要记住的是：

- **严格** 对应 `lower_bound`
- **允许相等** 对应 `upper_bound`

这个规律非常重要。

---

## 九、为什么这一类题叫“线性 DP”

很多人会疑惑：

- 明明 `O(n log n)` 那个做法看起来像贪心 + 二分
- 为什么还是放在线性 DP 里？

因为它的原始出发点仍然是经典 DP：

- `dp[i]` 表示以 `i` 结尾的最优值

只是后来利用了结构性质，把转移优化掉了。  
所以本质上它还是从 DP 出发，只是被优化成了贪心 + 二分。

这也是算法学习里很重要的一点：

> 很多“高级做法”，其实都是从朴素 DP 优化来的。

所以一定要先理解 `O(n^2)` 版本，再去理解 `O(n log n)` 版本。

## 十、Dilworth 定理相关结论

这是最长子序列类问题里一个非常经典的理论背景。

如果把序列看成偏序集合，那么可以得到下面一些常见结论：

1. 最长上升子序列长度 = 最少把序列划分成多少个不上升子序列
2. 最长下降子序列长度 = 最少把序列划分成多少个不下降子序列

这些结论在很多题里会以“最少分组数”“最少链覆盖数”的形式出现。

如果你以后做到下面这种题：

- 把一个序列分成最少若干组
- 每组满足单调
- 问最少组数是多少

那就要想到它可能和 LIS / LDS 有对偶关系。

## 十一、常见易错点

## 1. 把子序列当成子数组

子序列可以跳着选，子数组必须连续。  
这是最基础但也最常见的错误。

---

## 2. 不清楚 `dp[i]` 到底表示什么

如果状态定义不清楚，转移一定乱。  
最推荐的基础定义是：

- `dp[i]` 表示以 `a[i]` 结尾的最优值

---

## 3. `lower_bound` 和 `upper_bound` 用反

这是二分优化版本里最高频的错误之一。

记法：

- 严格上升：`lower_bound`
- 不下降：`upper_bound`

---

## 4. 误以为 `f` 数组就是实际方案

不是。  
`f[len]` 只是“长度为 `len` 的某类子序列的最小结尾”，它不一定对应最终答案中的真实方案。

它只是一个用于贪心维护的辅助数组。

---

## 5. 只会背 `O(n log n)`，不会解释为什么

如果你只能背模板，却不知道：

- 为什么维护最小结尾
- 为什么可以替换
- 为什么二分成立

那么这类题一旦稍微变形，你就很容易不会做。

所以请你一定先理解思想，再记模板。

---

## 十二、建议的学习顺序

如果你是第一次系统学最长子序列，建议按这个顺序来：

### 第一步
先彻底理解 `O(n^2)` 的 DP：

- 状态是什么
- 为什么这样转移
- 为什么答案取 `max(dp[i])`

### 第二步
再去理解 `O(n log n)` 的贪心 + 二分优化：

- `f[len]` 表示什么
- 为什么维护最小结尾
- 为什么 `f` 单调

### 第三步
再去熟悉四种类型之间的变化：

- LIS
- LNDS
- LDS
- LNIS

### 第四步
最后再去接触与其相关的结论：

- 最少划分成若干单调子序列
- Dilworth 定理
- 偏序建模

---

## 十三、最后总结

这份笔记最希望你记住三句话：

### 1. 最长子序列类问题，最基础的状态是“以某个位置结尾”
这会让转移最自然。

### 2. `O(n log n)` 的核心不是二分，而是“维护每个长度下最小可能结尾”
二分只是因为这个数组恰好单调。

### 3. 严格与不严格的区别，本质体现在 `lower_bound` 和 `upper_bound`
这点一定要熟。

如果你以后把这三句话记牢，那么最长子序列这一类题的主干就算真正掌握了。
