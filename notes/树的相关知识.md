# 树的相关知识

## 前言

树论题是算法竞赛里非常高频的一类题。  
很多同学一开始学树，总是把各种概念混在一起：

- 树的直径
- 树的中心
- 树的重心
- LCA
- DFS 序
- 重链剖分

这些东西名字很像，但含义和用途并不一样。  
这份笔记的目标不是把所有树论内容一次性讲完，而是先把最常见、最容易混淆的基础知识整理清楚。

读这份笔记时，建议你重点区分三件事：

1. 这个概念的**定义**是什么；
2. 这个概念的**性质**是什么；
3. 这个概念在题目里通常是怎么被使用的。

---

# 一、树的基础认识

## 1. 什么是树

树是一类特殊的无向图，它满足：

- 连通
- 无环

如果一棵树有 `n` 个点，那么它一定有：

- `n - 1` 条边

这个性质非常重要，因为它意味着：

- 树上任意两点之间的简单路径唯一；
- 很多图论问题在树上会变得简单。

---

## 2. 树题为什么常用 DFS

因为树没有环，所以从一个点往下搜时，通常只要记住父节点，就能避免回头。

树上最常见的遍历方式就是：

- `dfs(u, fa)`

含义是：

- 当前在 `u`
- `fa` 是 `u` 的父节点

这样写的好处是：

- 容易求子树大小
- 容易做树形 DP
- 容易处理深度、父亲、重儿子等信息

---

# 二、树的直径

## 1. 定义

树的直径，指的是：

> 树上任意两个点之间的最长简单路径

也可以理解为：

- 树上最远的两点之间的距离

这个“距离”通常指：

- 边数
- 或边权和

要看题目定义。

---

## 2. 为什么树的直径重要

因为树的直径经常出现在这些场景里：

- 求树上最远点对
- 求树的中心
- 做换根 DP
- 分析树的形状
- 判断某种最优结构

很多树题的第一步，就是先问：

> 这题和树的直径有没有关系？

---

## 3. 两次搜索求树的直径

这是树论里最经典的结论之一。

### 结论

1. 从任意一个点 `s` 出发，找到离它最远的点 `a`
2. 再从 `a` 出发，找到离它最远的点 `b`
3. 路径 `a -> b` 就是一条树的直径

### 为什么这样做是对的

你可以这样理解：

- 第一次搜索把你带到了“树的一端”
- 第二次搜索从这一端再走到最远，就会到达另一端

树的结构决定了，这样找到的路径一定是最长路径之一。

---

## 4. 常见实现

如果是无权树，可以用：

- DFS
- BFS

如果是有权树，通常用：

- DFS
- 或树形 DP

最常见写法是 DFS 版本：

```cpp
int mx, pos;
vector<vector<int>> g;
vector<int> dep;

void dfs(int u, int fa, int d)
{
    if(d > mx)
    {
        mx = d;
        pos = u;
    }
    for(auto v : g[u])
    {
        if(v == fa) continue;
        dfs(v, u, d + 1);
    }
}
```

用法：

1. 先 `dfs(任意点, 0, 0)` 找到 `a`
2. 再 `dfs(a, 0, 0)` 找到 `b`
3. `mx` 就是直径长度

---

# 三、树的中心

## 1. 定义

树的中心，是指：

> 位于树的直径中间的位置

更准确地说：

- 如果树的直径上有奇数个点，那么中心只有一个；
- 如果树的直径上有偶数个点，那么中心有两个。

---

## 2. 树的中心的性质

树的中心有一个非常重要的性质：

> 它到树上所有点的最远距离最小

这句话的意思是：

- 如果你想选一个点，使它离整棵树“尽量均衡”
- 那么应该选树的中心

这类性质常用于：

- 建服务站
- 选根
- 最小化最大距离

---

## 3. 怎么找树的中心

先求树的直径，然后看直径路径的中间位置即可。

所以很多时候：

- 求中心的前提是先求直径

---

## 4. 容易混淆的点

很多同学会把“树的中心”和“树的重心”混淆。  
它们不是一个东西。

### 树的中心关注的是：

- 距离

### 树的重心关注的是：

- 子树大小

这是两个完全不同的概念。

---

# 四、树的重心

## 1. 定义

对于一棵树，如果把某个点当作根，那么这个点的所有子树中，最大的那棵子树尽量小。  
满足这一条件的点，叫做树的重心。

更形式化地说：

删掉某个点 `u` 后，树会变成若干个连通块。  
如果这些连通块中最大的大小最小，那么 `u` 就是重心。

---

## 2. 为什么重心重要

树的重心常用于：

- 点分治
- 选最优分割点
- 分析子树大小平衡性
- 最小化某些子树规模上界

它是“按规模平衡”的代表点。

---

## 3. 重心的经典性质

### 性质 1

如果 `u` 是树的重心，那么删掉 `u` 后，所有连通块的大小都不超过整棵树大小的一半。

这是重心最核心的判定性质。

### 性质 2

一棵树的重心最多有两个。

### 性质 3

如果有两个重心，那么它们一定相邻。

### 性质 4

重心到所有点的距离和最小。

这个性质很常见，但比赛里更常直接使用的是前两个性质。

---

## 4. 如何求树的重心

这是一个标准 DFS 过程。

我们维护：

- `sz[u]`：以 `u` 为根的子树大小
- `mx[u]`：删掉 `u` 后最大连通块的大小

对每个点 `u`：

1. 先统计每个儿子子树大小 `sz[v]`
2. 最大块候选之一是每个儿子的 `sz[v]`
3. 还要考虑“父亲那一侧”的大小，也就是 `n - sz[u]`

所以：

```cpp
mx[u] = max(mx[u], sz[v]);
mx[u] = max(mx[u], n - sz[u]);
```

最后取 `mx[u]` 最小的点即可。

---

## 5. 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 200005;
vector<int> g[N];
int n;
int sz[N], mx[N];
int ans, best;

void dfs(int u, int fa)
{
    sz[u] = 1;
    mx[u] = 0;
    for(auto v : g[u])
    {
        if(v == fa) continue;
        dfs(v, u);
        sz[u] += sz[v];
        mx[u] = max(mx[u], sz[v]);
    }
    mx[u] = max(mx[u], n - sz[u]);

    if(mx[u] < best)
    {
        best = mx[u];
        ans = u;
    }
}

int main()
{
    cin >> n;
    for(int i = 1; i < n; i++)
    {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }

    best = 1e9;
    dfs(1, 0);
    cout << ans << "\n";
    return 0;
}
```

# 五、树的中心和树的重心的区别

这是树论基础里最常见的混淆点，一定要分清楚。

## 1. 树的中心

关注的是：

- 到所有点的最远距离尽量小

本质关键词：

- 距离
- 直径中点

## 2. 树的重心

关注的是：

- 删掉它之后，最大的连通块尽量小

本质关键词：

- 子树大小
- 平衡分割

---

## 3. 一句话区分

你可以这样记：

- **中心看距离**
- **重心看大小**

---

# 六、LCA 最近公共祖先

## 1. 定义

在一棵有根树上，两个点 `x, y` 的最近公共祖先 `LCA(x, y)` 指的是：

> 同时是 `x` 和 `y` 的祖先，并且深度尽可能大的那个点

换句话说，就是：

- 离 `x, y` 最近的那个公共祖先

---

## 2. LCA 为什么重要

LCA 是树论里最基础、最重要的工具之一。

它常用于：

- 查询两点路径
- 求两点距离
- 处理树上路径信息
- 树上差分
- 虚树
- 重链剖分

很多树题的底层工具就是 LCA。

---

## 3. 倍增求 LCA 的思想

这是最经典的 LCA 做法之一。

### 预处理内容

- `dep[u]`：点 `u` 的深度
- `fa[u][j]`：点 `u` 往上跳 `2^j` 步到的祖先

### 查询过程

假设要查询 `LCA(x, y)`：

1. 如果 `x` 更深，就先把 `x` 跳到和 `y` 同一深度
2. 然后从大到小尝试同时往上跳
3. 一直跳到它们刚好位于 LCA 的下面
4. 最后返回它们的父亲

---

## 4. 为什么倍增能做到对数复杂度

因为每次都按二进制跳：

- `1`
- `2`
- `4`
- `8`
- ...

所以一次查询只需要：

- `O(log n)`

---

## 5. 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 500005;
const int LOG = 20;

vector<int> g[N];
int dep[N], fa[N][LOG + 1];

void dfs(int u, int f)
{
    fa[u][0] = f;
    dep[u] = dep[f] + 1;
    for(int j = 1; j <= LOG; j++)
    {
        fa[u][j] = fa[fa[u][j - 1]][j - 1];
    }
    for(auto v : g[u])
    {
        if(v == f) continue;
        dfs(v, u);
    }
}

int lca(int x, int y)
{
    if(dep[x] < dep[y]) swap(x, y);

    int d = dep[x] - dep[y];
    for(int j = 0; j <= LOG; j++)
    {
        if(d >> j & 1) x = fa[x][j];
    }

    if(x == y) return x;

    for(int j = LOG; j >= 0; j--)
    {
        if(fa[x][j] != fa[y][j])
        {
            x = fa[x][j];
            y = fa[y][j];
        }
    }

    return fa[x][0];
}
```

# 七、LCA 常见用途

## 1. 求树上两点距离

若边权都是 `1`，则：

$$
dist(x, y) = dep[x] + dep[y] - 2 \times dep[lca(x, y)]
$$

如果有边权，则通常把 `dep` 改成“根到该点的距离和”即可。

---

## 2. 判断祖先关系

如果你还有 DFS 序，那么可以快速判断：

- 一个点是不是另一个点的祖先

这在很多树上问题中都很常见。

---

## 3. 处理树上路径

树上两点路径可以拆成：

- `x -> lca`
- `y -> lca`

很多树上路径统计，本质都绕不开这个拆分。

---

# 八、重链剖分和 LCA 的关系

很多同学会问：

- 我已经会倍增 LCA 了，为什么还要学重链剖分？
- 我已经会重链剖分了，还需要倍增 LCA 吗？

其实它们侧重点不一样。

## 1. 倍增 LCA

优点：

- 好写
- 好理解
- 查询快
- 适合只做 LCA 和距离问题

## 2. 重链剖分

优点：

- 不仅能求 LCA
- 还适合处理树上路径修改、路径查询、子树修改、子树查询

所以：

- 如果题目只是求 LCA，倍增就够了；
- 如果题目还要维护路径信息，通常就要考虑重链剖分。

先把四个概念区分清楚：

- 直径
- 中心
- 重心
- LCA

这是最重要的。

重点理解这几个问题：

1. 为什么两次搜索可以求直径？

---

例如：

- 如果题目问“最远点对”，想到直径
- 如果题目问“离所有点最均衡”，想到中心
- 如果题目问“删掉后分得最均匀”，想到重心
- 如果题目问“两点路径”，想到 LCA

做到这一步，才算真正把知识点和做题联系起来。

# 十、总结

树的相关知识里，最基础但也最容易混淆的，就是下面几组概念：

## 1. 直径 vs 中心 vs 重心

- 直径：最长路径
- 中心：直径中点，关注距离
- 重心：平衡分割点，关注子树大小

## 2. LCA 是树上路径问题的基础工具

很多树上问题只要涉及：

- 两点关系
- 两点距离
- 两点路径

都要优先想 LCA。

## 3. 做树题的关键不是背概念，而是学会识别信号

以后看到树题时，先问自己：

- 这题是不是在问最远点对？  
  如果是，想直径。
- 这题是不是在问最均衡位置？  
  如果是，想中心或重心。
- 这题是不是在问两点路径？  
  如果是，想 LCA。

如果你能形成这种条件反射，树论基础就算真正入门了。
