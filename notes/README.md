# notes 笔记目录说明

## 目录定位

这个目录用于存放 **算法竞赛相关的专题讲义、知识点笔记、思路总结**。

和 `algorithm/` 不同，这里的内容不追求“点开即抄”，而更强调：

- 为什么这样做
- 什么时候该想到这个模型
- 常见易错点是什么
- 这些知识点之间是怎么联系起来的

所以你可以把这个目录理解成：

- 学习材料
- 复习讲义
- 赛后沉淀
- 个人知识库

---

## 和其他目录的区别

### 1. `algorithm/`
放的是：

- 可以直接复制到比赛代码中的模板
- 常见数据结构和算法实现
- 尽量接口统一、方便实战

例如：

- 树状数组
- 线段树
- 并查集
- LCA
- 最短路
- 拓扑排序
- Trie
- 字符串哈希
- 组合数
- 欧拉路
- 矩阵快速幂

### 2. `notes/`
放的是：

- 专题讲义
- 公式推导
- 思路总结
- 比赛中提炼出的高频技巧
- 不一定适合直接复制到代码里的“理解材料”

### 3. `Codeforces/`
放的是：

- 比赛代码
- 按场次整理的内容
- 场次知识点总结
- 比赛分类索引

## 后续维护原则

为了让这个目录长期保持清晰，建议以后继续遵守下面这些规则：

### 1. 这里放“讲义”，不放“比赛模板”
如果一个文件更适合直接复制进代码，就优先放到：

- `algorithm/`

而不是这里。

### 2. 这里要多讲“为什么”
这里的内容最好偏：
- 解释
- 思路
- 易错点
- 什么时候该想到

而不只是丢一段代码。

### 3. 比赛里提炼出的高频技巧，可以继续单独沉淀
比如以后如果又出现了：
- 特别典型的扫描线技巧
- 特别典型的前后缀优化
- 特别典型的构造思维
- 特别典型的图建模

就可以继续单独新建一份专题笔记。
